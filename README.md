# 邻里圈 - 社区小程序

一个面向小区居民的社区小程序，基于微信云开发。

## 功能模块

### 📱 首页
- 天气展示（西安灞桥区）
- 新闻资讯
- 技能墙入口
- 最新公告
- 热门动态

### 💬 社区（核心）
- 帖子列表（内容 + 图片 + 三连按钮）
- 发帖：最多6张图片 + 文字，支持 #标签
- 搜索帖子
- 点赞/评论/转发
- 评论通知订阅

### 👤 我的
- 一键登录
- 用户设置：用户名、头像、期号、楼号
- 我的发布、我的点赞
- 联系开发者

### 🔧 技能墙
- 技能发布（类目、报价、电话）
- 技能搜索
- 线下成交模式

## 技术栈

- **前端**: 微信小程序原生框架
- **后端**: 微信云开发
- **数据库**: 云开发 JSON 文档数据库
- **存储**: 云开发文件存储

## 快速开始

### 1. 导入项目
1. 下载微信开发者工具
2. 导入项目，AppID: `wxe5255795fa333b60`
3. 填入云开发环境ID到 `miniprogram/app.js` 的 `globalData.env`

### 2. 初始化云开发
1. 开通云开发
2. 创建数据库集合（见 DATABASE.md）
3. 部署云函数

### 3. 配置
- 修改 `utils/config.js` 中的天气、新闻API配置
- 添加 tabBar 图标到 `assets/icons/`
