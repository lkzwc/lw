## 修复投票 BUG + 重构投票横幅

- **BUG 根因**：`api.js` `createVote` 用 `data: { vote, ... }` 设对象，但 `vote` 字段初始 `null`，云数据库把对象展平为 `vote.deadline` 嵌套赋值，导致 `Cannot create field 'deadline' in element {vote: null}`
- **fix**：`createVote` 改用 `_.set(voteData)` 强制覆盖；`discussions.create` 去掉 `vote: null` 预置（不存在比 null 好）
- **数据模型**：`vote: { title, deadline, deadlineTs, createdAt }`，`deadlineTs` 是解析后的时间戳，用于倒计时判断
- **投票横幅 UI**：议题型信息下方展示渐变横幅，包含标签（投票中/投票结果）、进度条（绿色赞成条+红色底）、票数标签、倒计时（每30秒刷新）
- **三态交互**：未截止+未投票→渐变按钮投票；未截止+已投票→"已投票 · 剩余X小时"；已截止→"投票已截止"仅展示结果
- **旧数据兼容**：无 `deadlineTs` 的存量投票，`isDeadlinePassed()` 从 `deadline` 字符串反向解析判断是否截止
- **倒计时生命周期**：`onShow` 启动 / `onHide`+`onUnload` 停止，防止内存泄漏
