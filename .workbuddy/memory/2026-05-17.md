11. **真机图标不显示修复 - base64 内联字体** - 时间线页面真机图标不显示，根因是 `wx.loadFontFace()` 传本地路径在真机不生效。彻底修复：
    - **iconfont.wxss @font-face 改为 base64 data URL** - 将 woff2 文件 base64 编码（约 9.5KB）内联到 CSS，不再依赖本地文件路径。
    - **app.js loadFontFace 也改为 base64 data URL** - 双重保障，并增加云存储降级方案。
    - 同时发现时间线页面本身对 iconfont 样式引用没有问题（通过 app.wxss 全局导入），主要问题是字体文件加载方式。

12. **真机字体加载第二次修复 - 运行时读取文件方案** - base64 内联到 wxss 可能被解析器截断导致样式失效，改用运行时读取方案：
    - 回退 iconfont.wxss @font-face 为本地路径（开发工具可用）
    - app.js 重新实现 `loadIconFont`：三策略级联
      - **策略1**: `fs.readFileSync('/assets/fonts/iconfont.woff2', 'base64')` 运行时读取包内文件生成 base64 data URL
      - **策略2**: 同上，使用 ttf 文件（延后 200ms）
      - **策略3**: 硬编码 base64 fallback（延后 500ms）

13. **carpool 拼车页修复** - 修复两个问题：
    - **筛选按钮 data 属性不匹配**：WXML 用 `data-filter` 但 JS 读取 `e.currentTarget.dataset.type`，导致筛选点击后 query 条件为 `type: undefined`，返回空结果。已改为 `data-type` 统一。
    - **路线卡片路径文字溢出**：`.route-path` 未使用 flex 布局，路径文字溢出时换行/截断显示异常（"测...说→西安"）。改为 flex 布局，`.path-text` 加 `flex:1` + `text-overflow: ellipsis`。同时添加 `formatRoutes` 函数保证数据字段不为空。
