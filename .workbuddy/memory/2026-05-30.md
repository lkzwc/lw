# 2026-05-30 工作日志

## 社区评论功能修复

### 问题
点击帖子后评论半屏弹窗展开，但评论列表始终为空

### 根因
`community.js` 的 `loadComments` 和 `onSendComment` 直接操作 `db.collection('post_comments')`，但项目中的评论数据按 `DATABASE.md` 和 `api.js` 规范存储在 **`comments` 集合**，由 `api.comment` 模块统一管理。集合名对不上，查询永远返回空。

### 修复
- `loadComments` → 改用 `api.comment.getList(postId)` 
- `onSendComment` → 改用 `api.comment.create({ postId, content })`，乐观更新提前到 API 调用之前，失败时回滚
- `api.comment.create` 已内置 `commentCount` 递增（`_.inc(1)`），移除了重复的 commentCount 更新逻辑

### 同步修复（上一轮遗留）
- `community.wxss`: 删除 283-481 行旧版重复样式（199 行），只保留新版 flex 列布局版本
- `community.js`: `onPostTap`/`onCommentBtnTap` 加 `wx.hideTabBar()`，`onCloseCommentDialog` 加 `wx.showTabBar()`
- 评论输入框通过 `flex:1; overflow-y:auto` 固定在弹窗底部
